## 为什么之前会"乱"

1. **编号错位**：文件是按你写代码的先后编号的，技能树是按知识依赖编号的。元组是最先写的却排在 Day 13，被你存成了 `day15_tuple.py`，于是出现「day14 两个文件、day15 两个文件、day13 其实是字典」。
2. **Day 11 / Day 12 没有文件**：这两项是口头过的，没留代码 → Day 16 要"重构 Day 12"时无从下手。
3. **`day16_comprehension.py` 是提前迁入的通用练习**，不是 Day 16 的验收件，且最后一题空着 → 容易被误判为"Day 16 已完成"。
